## Getting Started

### Prerequisites
Before diving into these projects, ensure you have:
- Basic understanding of Linux commands
- Git installed and configured
- A cloud account (Azure/AWS) with free tier access
- Docker installed locally
- Code editor (VS Code recommended)

### How to Use This Portfolio
1. **Start with your current skill level** - Don't skip ahead!
2. **Complete projects in order** - Each builds upon the previous
3. **Read the detailed guides** - Each project has comprehensive documentation
4. **Practice in a safe environment** - Use free tiers and home lab setups
5. **Document your learning** - Keep notes of challenges and solutions

## Project Roadmap

### Beginner Level

Perfect for those new to DevOps or coming from other technical backgrounds.

#### 1. DevOps Home Lab - Prerequisites & Docker Compose
**Learning Goals:** Set up a local development environment and practice multi-container applications

- **Repository:** [DevOps Home Lab 2025](https://github.com/Osomudeya/DevOps-Home-Lab-2025)
- **Focus Areas:**
  - Local development environment setup
  - Docker Compose fundamentals
  - Multi-container application deployment
  - Basic container orchestration

**Estimated Time:** 30-45 minutes  
**Technologies:** Docker, Docker Compose, Linux

#### 2. Infrastructure as Code with Terraform
**Learning Goals:** Learn Terraform basics by provisioning Azure resources

- **Repository:** [Side DevOps Projects](https://github.com/Osomudeya/side-devops-projects)

  - Azure resource provisioning
  - Infrastructure versioning
  - Basic cloud concepts

**Estimated Time:** 2-3 weeks  
**Technologies:** Terraform, Azure CLI, Azure Portal

#### 3. Vagrant Multi-Tier Application Stack
**Learning Goals:** Understand multi-tier architecture and manual service configuration

  - Virtual machine management with Vagrant
  - Multi-tier application architecture
  - Service configuration and integration
  - Basic networking concepts

**Estimated Time:** 1-2 weeks  
**Technologies:** Vagrant, VirtualBox, MySQL, Nginx, Tomcat

## Recommended Learning Path

Follow this structured path to build your DevOps skills progressively:

| Milestone | What You Learn | Estimated Time | Difficulty | Projects |
|-----------|----------------|----------------|------------|----------|
| **0. Prerequisites** | Development environment setup | 15-30 min | Beginner | DevOps Home Lab - Prerequisites |
| **1. Containerization** | Multi-container application deployment | 30-45 min | Beginner | DevOps Home Lab - Docker Compose |
| **2. Infrastructure as Code** | Cloud resource provisioning | 2-3 weeks | Beginner | Terraform with Azure |
| **3. CI/CD Fundamentals** | Automated testing and deployment | 1-2 weeks | Intermediate | GitHub Actions Pipeline |
| **4. Container Orchestration** | Production app deployment | 2-3 weeks | Intermediate | Kubernetes Basics |
| **5. Production Networking** | Internet access & load balancing | 1-2 weeks | Intermediate | NGINX Ingress |
| **6. Observability** | Monitoring and alerting | 2-3 weeks | Intermediate | Prometheus & Grafana |
| **7. Multi-Environment** | Environment management | 2-3 weeks | Advanced | Multi-Environment Infrastructure |
| **8. GitOps** | Automated deployments | 2-3 weeks | Advanced | ArgoCD GitOps |
| **9. Global Production** | Worldwide deployment | 3-4 weeks | Advanced | Global Production Setup |

### Learning Path Tips:
- **Don't skip milestones** - Each builds on the previous
- **Take your time** - Master each concept before moving on
- **Practice regularly** - Consistency beats intensity
- **Document everything** - Keep notes of challenges and solutions
- **Join communities** - Get help and share your progress
